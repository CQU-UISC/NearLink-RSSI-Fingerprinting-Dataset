The first Dataset include NearLink, BLE and Wi-Fi
This RSSI fingerprinting dataset is a comprehensive set of Received Signal Strength Indicator (RSSI) readings collected from three different types of scenarios. Three wireless technologies were used which consisted of
NearLink (SLE 1.0), 
Bluetooth Low Energy (BLE 5.2),
WiFi (IEEE 802.11. AX 2.4GHz band).
In the experiment, the equipment used includes BearPi Pico H3863 for reading RSSI data and an autonomous robot for automated data collection.
